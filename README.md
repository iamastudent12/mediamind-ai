# MediaMind AI

A personalized mental health content platform built with React and Vite.

## Setup

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Features
- Daily Mood Check-In with slider and mood tags
- Personalized Content Feed matched to mood score
- Progress Dashboard with 7-day chart
- Profile with crisis resources (988 Lifeline)

## Built with
- React 18
- Vite
- Recharts
- Lucide React
